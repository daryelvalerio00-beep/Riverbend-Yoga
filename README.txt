Before submission:
1. Add all official ZIP assets.
2. Open index.html in your IDE/browser and test all four pages.
3. Test the navigation and form fields.
4. Test the layout at a narrow/mobile width and a larger desktop width.
5. Publish the project to a PUBLIC GitHub repository.
6. Enable GitHub Pages or use your IDE preview to get a real working preview URL.
7. Paste your actual repository and preview URLs into the Word template.
8. Take a screenshot of the running website and insert it in Section 4.

The form is a front-end example only; it will not send a real message without a connected form service.
